# OBX MEDIA Landing Page

A responsive, mobile-first landing page for OBX MEDIA — Digital Marketing & Creative Agency.

## Files
- `index.html` — page structure/content
- `style.css` — responsive visual design
- `script.js` — mobile menu, year and enquiry form
- `favicon.svg` — OBX favicon

## Before publishing
Open `script.js` and replace:
`YOUR-EMAIL-HERE@example.com`
with OBX MEDIA's real business email.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `obx-media`.
2. Upload all files in this folder to the repository root.
3. Commit the files.
4. In GitHub, open **Settings → Pages**.
5. Under the Pages source, choose **Deploy from a branch**, select `main`, and select `/ (root)`.
6. Save. GitHub will provide the live Pages URL after deployment.

The site is static, so it does not require a server or database.
